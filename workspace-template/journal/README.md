# Journal

Shared memory between agents. Agents never talk to each other directly: they write here and read here.

- File name: `YYYY-MM-DD_HHMM_<agent>_<topic>.md`
- Use `ads-master/templates/JOURNAL_ENTRY.md` (structure below).
- Never edit another agent's entry. Add a new entry that references it.

```
# <Title>
Date: YYYY-MM-DD HH:MM | Agent: <slug> | Tags: performance, decision, change, alert, learning, request
## What happened
## Why it matters
## Data (with source)
## Action items (owner agent or human)
## Related files
```
