## How to verify a claim quickly
1. Open the cited official URL and search the page for the feature name.
2. If the page is a monthly roundup, check the following month's roundup for status changes (pilot to GA, market expansion).
3. Check the help center article for the feature for limits and markets.
4. Check the UI: if a setting does not appear in the account, record "not available in this account" with the date.
5. Update the label in the module (for example from [Unverified] to [Official, YYYY-MM]) and add a row to the freshness log.
