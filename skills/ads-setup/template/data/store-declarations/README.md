# Store declarations

One JSON file per store (`apple.json`, `google.json`), recorded by `store-submission` from the answers given in App Store Connect and Play Console: ads, in-app purchases, random items and the age rating answers. `monetization_conformance.py --declarations` checks each file against `data/monetization-policy.json`. Format: `skills/game-monetization/references/policy-file-and-conformance.md`. Samples: `skills/game-monetization/scripts/samples/*-store-declarations.json`.
